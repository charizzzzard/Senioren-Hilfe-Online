„Phishing“ bedeutet: Jemand versucht, an Ihre Daten zu kommen – wie beim Angeln, nur mit Nachrichten als Köder. Passiert das per SMS, sprechen Fachleute von **Smishing**.

## Ein Beispiel aus dem Alltag

Till bekommt eine SMS: „Ihr Paket konnte nicht zugestellt werden. Bitte bestätigen Sie Ihre Adresse.“ Darunter steht ein Link. Er erwartet tatsächlich ein Paket und will schon tippen. Dann stutzt er: Warum kommt die Nachricht von einer unbekannten Handynummer?

Genau das ist typisches Smishing. Die Verbraucherzentralen warnen vor solchen SMS von angeblichen Paketdiensten.

## Was die Betrüger wollen

Wer auf den Link tippt, landet auf einer gefälschten Seite. Laut Verbraucherzentrale können die Folgen sein:

- eine **schädliche App** auf dem Handy,
- **Massen-SMS**, die vom eigenen Handy verschickt werden,
- **Abofallen** oder angebliche Gebühren, mit denen Kreditkartendaten erbeutet werden.

## Woran Sie Smishing erkennen

- Die SMS kommt **überraschend** und enthält einen **Link**.
- Sie stammt angeblich von einem Paketdienst, einer Bank oder einer Behörde.
- Sie sollen **schnell handeln** oder eine kleine Gebühr bezahlen.

## Was Sie tun können

1. **Nicht auf den Link tippen** und **nicht antworten**.
2. Die SMS **löschen**.
3. Erwarten Sie wirklich ein Paket, prüfen Sie den Status **direkt auf der Internetseite** des Paketdienstes.
4. Spam-SMS können Sie bei der **Bundesnetzagentur** melden.

## So bekommen Sie weniger solche SMS

Die Verbraucherzentrale nennt einige einfache Schritte:

- In vielen Nachrichten-Apps können Sie einstellen, dass nur SMS von Nummern aus Ihren **Kontakten** angezeigt werden. Manche Handys haben auch einen **Spam-Filter**.
- Geben Sie Ihre **Handynummer** nur dort an, wo es wirklich nötig ist.
- Lassen Sie bei Ihrem Mobilfunkanbieter eine **Drittanbietersperre** einrichten. Dann können fremde Firmen nichts über Ihre Handyrechnung abbuchen.

Eine ausführliche Anleitung – auch für den Fall, dass Sie schon getippt haben – finden Sie in [Betrugs-SMS erkennen](/artikel/betrugs-sms-erkennen/).
