Ein Foto per WhatsApp zu verschicken, gehört zu den schönsten Dingen, die ein Handy kann. Ein Enkelkind sieht den Garten, die Tochter sieht das neue Sofa – ganz ohne Briefmarke. Und das Beste: Es ist leichter, als es aussieht.

**Danach können Sie ein Foto per WhatsApp senden** – entweder ein Bild, das schon auf Ihrem Handy ist, oder eines, das Sie gerade neu aufnehmen. Wir zeigen beide Wege für das iPhone und für Android-Handys.

## Bevor es losgeht

Sie brauchen nur zwei Dinge: den **Chat** mit der Person, die das Foto bekommen soll, und das Foto selbst. Das kann schon in Ihrer Fotosammlung liegen – auf dem iPhone heißt sie „Fotos“, auf vielen Android-Handys „Galerie“.

Beim allerersten Mal fragt Ihr Handy vielleicht, ob WhatsApp auf Ihre Fotos zugreifen darf. Das ist normal. Erlauben Sie es – sonst kann WhatsApp keine Bilder verschicken.

## Auf dem iPhone

### Ein Foto aus Ihrer Sammlung senden

```klickpfad
Chat öffnen › Pluszeichen (Anhängen) › Fotos › Bild auswählen › Senden
```

1. Öffnen Sie den **Chat** mit der Person, die das Foto bekommen soll.
2. Tippen Sie auf das **Pluszeichen** – WhatsApp nennt es „Anhängen“.
3. Tippen Sie auf **„Fotos“**. Jetzt sehen Sie Ihre Bilder.
4. Tippen Sie das **Foto** an, das Sie schicken möchten.
5. Tippen Sie auf **„Senden“** – das ist das **Papierflugzeug im grünen Kreis**.

Möchten Sie noch ein zweites Bild dazulegen? Tippen Sie vor dem Senden im Textfeld noch einmal auf das **Pluszeichen**. Wählen Sie weitere Bilder aus und tippen Sie auf **„Weiter“**.

### Ein neues Foto aufnehmen und senden

1. Öffnen Sie den **Chat**.
2. Tippen Sie auf das **Kamera-Symbol**. Die Kamera öffnet sich.
3. Machen Sie das Foto.
4. Tippen Sie auf das **Papierflugzeug**, um es zu senden.

## Auf einem Android-Handy

### Ein Foto aus Ihrer Galerie senden

```klickpfad
Chat öffnen › Büroklammer (Anhängen) › Galerie › Bild auswählen › Senden
```

1. Öffnen Sie den **Chat** mit der Person, die das Foto bekommen soll.
2. Tippen Sie auf die **Büroklammer** – WhatsApp nennt sie „Anhängen“.
3. Tippen Sie auf **„Galerie“**. Jetzt sehen Sie Ihre Bilder.
4. Tippen Sie das **Foto** an, das Sie schicken möchten.
5. Tippen Sie auf **„Senden“** – das ist der **Pfeil nach rechts im Kreis**.

Mehrere Bilder auf einmal? Halten Sie in der Galerie den Finger etwas länger auf ein Foto. Dann können Sie weitere Bilder antippen.

### Ein neues Foto aufnehmen und senden

1. Öffnen Sie den **Chat**.
2. Tippen Sie auf das **Kamera-Symbol**.
3. Machen Sie das Foto.
4. Tippen Sie auf den **Pfeil**, um es zu senden.

## Hat es geklappt?

Das Foto steht jetzt als Ihre Nachricht im Chat. Geschafft! Die andere Person bekommt es wie eine ganz normale Nachricht.

Wundern Sie sich nicht, wenn das Bild beim Empfänger etwas weniger scharf aussieht als bei Ihnen. WhatsApp verkleinert Fotos beim Verschicken meist ein wenig. Wer Wert auf die volle Schärfe legt, findet vor dem Senden das Symbol **„HD“**: Dort können Sie zwischen „Standardqualität“ und „HD-Qualität“ wählen.

## Wenn es nicht klappt

**Ihre Fotos werden in WhatsApp gar nicht oder nur teilweise angezeigt?** Dann fehlt WhatsApp meist die Erlaubnis.

- **iPhone:** Öffnen Sie die iPhone-Einstellungen › „Apps“ › „WhatsApp“ › „Fotos“. Erlauben Sie dort den **vollen Zugriff**. Je nach iOS-Version heißt die Option etwas anders.
- **Android:** Öffnen Sie die Einstellungen › „Apps“ › „WhatsApp“ › „Berechtigungen“. Tippen Sie auf „Fotos und Videos“ und wählen Sie „Erlauben“. Die Namen können je nach Hersteller etwas abweichen.

**Das Foto lädt und lädt, wird aber nicht gesendet?** Meist liegt es an einer schwachen Internetverbindung. WhatsApp empfiehlt:

- das Handy einmal **neu starten**,
- **WhatsApp aktualisieren**,
- vom WLAN auf mobile Daten wechseln – oder umgekehrt.

**Viele Fotos auf einmal hängen fest?** WhatsApp weist selbst darauf hin, dass es dabei Probleme geben kann. Schicken Sie die Bilder lieber in kleinen Portionen.

!!! tipp "Ein Foto weiterleiten statt neu suchen"
    Sie haben ein schönes Foto von jemandem bekommen und möchten es weitergeben? Halten Sie den Finger auf das Bild und tippen Sie auf **„Weiterleiten“** – auf Android ist das ein Pfeil-Symbol. Wählen Sie den Chat aus und senden Sie. Das Bild bekommt beim Empfänger den Hinweis „Weitergeleitet“.
